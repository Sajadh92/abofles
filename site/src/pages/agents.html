Home/Agents

Meet the family.

{{agents}} agents, one job each, a fixed reply format each. Every one opens with STATUS and CONFIDENCE, so a weak answer escalates instead of slipping through. The uncle pays each by the task — never by the hour.

The five sides + the question gate

Each task, split by side.

One agent per side, small and cheap. Results flow forward as short summaries — no agent re-reads what the last one found.

🔍

Reader

abofles-reader

Finds files, maps code, collects facts. No opinions, no fixes. Usually Haiku · Low.

🧠

Analyst

abofles-analyst

Finds bugs, gaps and risks, compares options, ranks findings with a fix for each.

📐

Planner

abofles-planner

Writes the plan before code changes: numbered steps, files, risks, a verify step.

🛠️

Worker

abofles-worker

Writes and edits code, tests, docs and configs. On Opus at every tier by default.

✅

Verifier

abofles-verifier

Runs the tests, reviews the diff, checks docs against code. PASS or FAIL with evidence.

⚖️

Judge

abofles-judge

Sees every question before you do. Answers it from the repo — or explains why it's truly yours.

💬

Explainer

abofles-explainer

Turns a hard 🟠/🔴 decision into plain words: options, consequences, a recommendation, a table when it helps.

The helpers

The ones who keep the house in order.

🌿

Git

abofles-git

Owns every git and GitHub write: branches, worktrees, commits, merges, conflicts, PRs, tags, releases. Pushes only on your quoted words.

📋

Scrum

abofles-scrum

Scrum master for Jira, Linear, ClickUp, Asana, monday.com, Trello and GitHub Issues. Drafts first, writes only when you said so.

🗂️

Memo

abofles-memo

Tidies the work memo in the background on Haiku · Low: merges duplicate decisions, archives closed sessions. Never asks questions.

✅

Close

abofles-close

Answers “ready to archive?” on Sonnet 5.5: judges your own close rules and what you decided in chat against the check’s evidence. Read-only — it writes nothing.
