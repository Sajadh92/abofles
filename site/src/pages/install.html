Install

  1. Add the marketplaceType this in the Claude Code prompt box.{{cmd:/plugin marketplace add Sajadh92/abofles}}
  2. Install the pluginThe router, the hooks, the {{agents}} agents and the commands.{{cmd:/plugin install abofles@sajadh92}}
  3. Restart Claude CodeOr run /reload-plugins in an open session.

From the terminal instead? The same works with the CLI:

{{cmd:claude plugin marketplace add Sajadh92/abofles}} {{cmd:claude plugin install abofles@sajadh92}}

Add the pane (optional, recommended)

The abofles-guide mod draws the Abo Fles pane on the right of the Claude desktop app: Home, Running, Guide, Resume, Decisions, Agents and an Overrides editor. See every screen.

{{cmd:/plugin install abofles-guide@sajadh92}}

/abofles-pane opens or closes it. It also opens by itself once per session when it has something to show.

One line in CLAUDE.md

Add this to ~/.claude/CLAUDE.md so every session routes before it starts agents:

- Use the abofles skill once per session, before the first coding, design or marketing task or subagent (never re-invoke it per task: it stays in context), and tier every task with it.{{copy}}

Want different settings for one project? Add an ## abofles overrides block to that project's CLAUDE.md — or run /abofles:init and let it suggest one. All keys.

Turn on auto-update

Claude Code keeps auto-update off for marketplaces that aren't Anthropic's own. Turn it on once and every new version installs itself when Claude Code starts:

  1. Open the plugin manager{{cmd:/plugin}}
  2. Open MarketplacesPick sajadh92.
  3. Choose Enable auto-updateDone. New versions arrive at startup — the uncle delivers, free of charge.

The pane tells you too. With the pane installed, Home shows the version you run. When a newer one is installed but not loaded it offers Reload; when GitHub has a newer release it offers Update and a What's new link. Update check = off stops the GitHub check.

Update by hand

Prefer to choose when? Refresh the marketplace, then restart Claude Code:

{{cmd:/plugin marketplace update sajadh92}}

Open sessions keep the old version until they reload: /reload-plugins. What changed is always in the changelog.

Check it works

A dry run prints the route lines and a cost estimate without starting anything:

{{cmd:/abofles:route "fix refund rounding in payments"}}

You should see a 🔴 Critical workflow with Plan and Work on Opus 5.5 · Extra and the Finance, Security and Tester reviewers. Then just work as usual: the first agent of a session asks the agent-gate question once, and every task that started agents ends with a receipt.

  • /abofles:bill — what this session's agents cost, and what was saved
  • /abofles:status — agents per model and the open follow-ups
  • /abofles:resume — where was I?
  • /abofles:guide — the one thing to do next
  • /abofles:close — ready to archive? The close check, with proof

Requirements

  • Claude Code — CLI, desktop app or IDE extension. The pane needs the desktop app.
  • Python 3.8+ on the PATH as python3, python or py. Without Python the hooks step aside quietly and the skill still routes — nothing is enforced or logged.
  • macOS, Linux or Windows. On Windows, Claude Code uses Git Bash; the hooks lock files with msvcrt there.

Uninstall

No hard feelings. He'll only ask who's paying now.

{{cmd:claude plugin uninstall abofles@sajadh92}} {{cmd:claude plugin uninstall abofles-guide@sajadh92}}

Your ledgers live in ~/.abofles/ and the memo in each project's .claude/abofles-memo*; delete them if you want a clean slate.

Troubleshooting

  • Agents start without a route line. Check the CLAUDE.md line above, then start a new session.
  • An agent was refused. That's the hook doing its job: the message names the model and effort to pass. A missing model or effort, or Fable on a Read/Work/Verify agent, is always refused.
  • The pane shows an old version. Run /reload-plugins or press Reload on Home.
  • Still stuck? Open an issue on GitHub or send a DM to @abofles.
