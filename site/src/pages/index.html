How it works

You ask. He haggles. The work gets done.

You ask, like always

No new commands to learn. Type the task in Claude Code the way you already do.

He looks it up

One lookup finds the topic and its risk tier — 🟢 Minor to 🔴 Critical — and picks a model, effort and reply cap for each step: Read, Analyse, Plan, Work, Verify.

Agents run, you get the receipt

Hooks refuse any agent without a model and effort. At the end: agents, real tokens, real dollars, and what was saved.

FAQ

Questions the uncle gets at dinner.

Is it free?

Yes. Open source under MIT. No account, no sign-up, no “pro” tier. He'd never charge family.

Does it make Claude worse to save money?

No. With the default Matrix = quality, Opus writes, plans and analyses at every tier. Haiku and Sonnet only read and check. A FAIL or low confidence escalates one step at a time to a stronger setting.

Does it send my data anywhere?

No. The only network call is the optional update check: GitHub's public releases list, at most every 6 hours, none of your data. Update check = off turns it off. Ledgers and the memo stay on your machine.

I'm a designer / marketer. Is this for me?

Yes. Graphic design, video and motion, 3D and social and ads have their own topics and reviewers. It never posts, schedules or spends on its own — you press the button.

Which systems does it run on?

macOS, Linux and Windows (with Git Bash, which Claude Code uses there). It needs Python 3.8+ on the PATH. Without Python the hooks step aside and the skill still routes.

Is it made by Anthropic?

No. It's an independent open-source plugin for Claude Code, not made or endorsed by Anthropic.

What does “Abo Fles” even mean?

In Iraqi slang, ابو فليس is the stingy uncle who counts every fils — a thousandth of a dinar. You know the one. This plugin counts every token.

Let the uncle hold the wallet.
