# Commands and maintenance

Read when the user asks what a command does, or when editing the plugin.

- `/abofles:route <task>` — dry run: prints the `main:` line, every route line and the estimated units, starts nothing. Use it to check a plan before paying for it.
- `/abofles:bill [--all]` — agents per model and side, verdicts, top topics, the unit cost index, and the real spend (tokens, $, $ saved vs the main-session model). Reads the ledger the hook writes to `~/.abofles/ledgers/`.
- `/abofles:history [--all]` — one line per agent of this session (time, side, status, confidence, model·effort, tokens, $, saved) and the totals line: `bill.py --history`, the same rows and sums as the pane's Agents tab.
- `/abofles:pane` — the Abo Fles pane (resume, agents, overrides) is opened by the `abofles-guide` mod; without the mod it prints the resume block (`memo.py show`) and the agent history (`bill.py --history`).
- `/abofles:init [--dry-run]` — scans the project and adds a `## abofles overrides` block to its `CLAUDE.md`, with at most 5 suggested lines.
- `/abofles:status [--all] [--resolve <id> --trace <evidence>] [--unresolve <id>] [--session <sid>] [--trace <text>]` — session summary from the ledger: agents per model as bars, confidence, open follow-ups. `--resolve <id>` closes one once handled (refused without `--trace` evidence), `--unresolve <id>` reopens it; `--trace` writes a "by hand" line in the memo Journal.
- `/abofles:agents [auto | N | off | ask]` — show or set the agent gate: this task's budget, how many ran, the auto table.
- `/abofles:guide [--all]` — the 🧭 next line (what to do now, by priority), or the whole ladder.
- `/abofles:memo [path]` — writes the Now section of this session's memo file (`.claude/abofles-memo.d/<session>.md`; the main memo `.claude/abofles-memo.md` keeps Needs you, notes and the session index) for a sharper hand-off. Optional: `/compact` saves the memo by itself (`Memo on compact = auto`); with `off` the context watch points here. Unless `Memo agent = off` it also starts the memo agent in the background.
- `/abofles:resume [--all] [--resolve <n> <note>] [--reopen <n>] [--trace] [--note <text>]` — "where was I?": prints the resume block from the memo without re-reading anything; `--resolve` ticks a Needs-you item (the note is required), `--reopen` turns it back, `--trace` leaves a "by hand" Journal line, `--note` records a decision made in chat; `--all` prints the main memo and this session's file, `--main` the main memo only; `--repair [--dry-run] [--all] [--root <folder>]` runs `memo.py repair` (backup first, moves misfiled sessions home, tags what it can, reports the rest).

Topics live in `scripts/topics_data.py` (31 domains → areas → `Name | T# | signals[ | ov …][ | cap …][ | +reviewer]` lines, plus `SUGGESTIONS` — packages the lookup recommends per topic and stack); tiers, caps, reviewers, intents and workflows in `scripts/gen_matrix.py`. Edit, run `python3 scripts/gen_matrix.py` (`--check` in tests): it regenerates `references/topics.md` (domain table), `references/topic-index.md` (every topic, for people), `references/matrix.md`, `references/workflow.md` and `hooks/workflow.json` — the index `scripts/topic.py find|show|domains|list` and the hook read. Never edit the generated files by hand. Topic names referenced by the hook, tests or docs keep their spelling. Reply formats live in `agents/*.md` (plugin root), one file per side. Hooks live in `hooks/abofles_hook.py` (`pre` blocks and enforces the agent budget, `post` logs and checks sync replies or writes a `pending` line for background agents, `stop` fills that line on `SubagentStop`, `guard` warns on direct-read streaks, `start` writes the session marker and the resume block (and runs `Memo repair = auto` once per project), `receipt` refuses a stop without the receipt and journals it, `prompt` notes the effort and the break and, when a by-meaning memo check is due, offers the memo agent once per `Memo agent every` hours, `decision` logs questions and the gate answer, `qgate` guards questions, `sendmsg` unlocks the re-ask after a `SendMessage` to the Judge/Explainer; the CLI mode `tokens` prints the context size); the memo and gate CLIs in `scripts/memo.py` and `scripts/agents.py`; the status in `scripts/status.py`; the output style in `output-styles/receipt.md`; unit tests in `scripts/test_hooks.py`; the bill in `scripts/bill.py`; commands in `commands/*.md`.
