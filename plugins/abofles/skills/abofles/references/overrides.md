# Project override block and its forms

Read when a project `CLAUDE.md` has a `## abofles overrides` block, or the user asks to change a cell, cap, tier or setting.

The matrix is the same for every project. A project changes cells in its own `CLAUDE.md` (or project memory):

```
## abofles overrides
- Unit Test / Work = haiku·medium
- Financial & Amount Calculations / Verify = opus·xhigh
- Topic: Notifications & Messaging = T3
- Codebase Exploration & Onboarding / Read cap = 200
- Main session = sonnet·medium
- Sub session = opus·xhigh
- Session cap = 600
- Context marks = 500, 600, 700, 750, 800, 850, 900, 950
- Receipt = savings 30
- Break = 10
- Agents = auto
- Parallel = 3
- Agent budgets = 2, 3, 7, 12
- Questions = judge
- Pace = normal
- Language = Arabic
- Guide = on
- Resume = project
- Review gate = auto
- Review memory = 2
- Judge notes = critical
- Budget raise = auto
- Git guard = warn
- Reviewers: FIN = finance, security, tester
- Workflow: Code Health = Read, Work, Verify
- Review: Security / T4 = opus·xhigh
- Guide place = pane
- Resume place = pane
- Agents place = pane
- Running place = pane
- Receipt place = pane
- Memo agent = auto
- Memo agent every = 6
- Memo on compact = auto
- Continue after compact = auto
- Archive items = 7
- Archive sessions = 3
- Other items = hide
- Memo repair = manual
```

Thirty-eight forms: `Topic / Side = model·effort` (one cell), `Topic: Name = T#` (move a topic to another tier), `Topic / Side cap = N` (reply cap), `Main session = model·effort` (the model and effort a session should run on: when set, the hook's `main:` line and the pane compare with it instead of the tier table and say `fits your setting` or `suggest …, your setting`; a warning only, nothing is enforced), `Sub session = model·effort` (the same for a session another session started — the desktop app's side sessions, told apart by `spawnedFrom.sideSession` in the app's session record; unset, or where that record cannot be read, `Main session` applies), `Session cap = N` (units per session before the hook tells you to stop and ask), `Context marks = N, N, …` (thousands of tokens at which the context watch warns — the line shown is the default; a 200K-window model wants `100, 150, 180`; `500K` and `1M` read too, 0 is skipped), `Receipt = full | short | savings N | off` (receipt form, see Step 6), `Break = N | off` (minutes away before the resume block is shown again; default 10), `Agents = ask | auto | N | off` (the agent gate: ask once per session — default —, size every task by tier, a fixed budget per task, or no budget), `Parallel = M` (background agents running at once, default 3), `Agent budgets = a, b, c, d` (agents per tier T1..T4 under `auto`), `Budget raise = auto | ask` (an over-budget agent under an auto budget raises it — half the tier's budget, at least 2, twice per task — instead of being denied; `ask` denies; default `auto`), `Git guard = warn | deny | off` (a risky git command — force push, `push --delete` / `:<ref>` / `--mirror` / `--prune`, `reset --hard` / `--merge` / `--keep`, `checkout <commit> <paths>`, `pull --rebase`, `submodule deinit -f`, a git named by a variable or `$(…)`, `rebase`, `branch -D` / `-f` / `-M`, `tag -d` / `-f`, `clean -f`, `checkout -f` / `-B`, `switch -f` / `-C`, `checkout -- <paths>`, `restore`, `stash drop` / `clear`, `commit --amend`, `update-ref`, `reflog expire --expire=now` / `reflog delete`, `branch -C`, `update-ref --stdin`, `gc --prune=now`, `worktree remove -f`, `filter-branch` / `filter-repo`, `git config alias.*`, …, also behind `sudo`, `env`, `timeout`, `nice`, `xargs`, shell keywords (`if`, `then`, `!`, …), `bash -lc`, `eval`, here-strings, `echo … | sh`, `find -exec`, `git -c alias.x=…` or `submodule foreach`, … — run outside `abofles:abofles-git` (only this plugin's agent is exempt): warn = a note, deny = blocked, off = silent; read-only git never triggers; default `warn`), `Questions = judge | off` (the question gate), `Language = Arabic` (the language owner questions are written in), `Guide = on | off` (the 🧭 next line), `Review gate = auto | on | warn | off` (the review gate at the receipt: auto = 🔴 refused once, 🟠 warned in the guide; on = 🟠 refused too; warn = never refused; off = silent), `Reviewers: <Domain code | Domain name | Topic> = security, tester | none` (replaces that domain's or topic's reviewers at T3 and T4; names as in workflow.md, lower case: security, finance, compliance, tester, qa, uiux, cleancoder, dba, ops, perf, data), `Workflow: <Domain | Topic> = Read, Work, Verify` (the steps of a `change` there — advice to the skill, not enforced), `Review: <Tag> / T<tier> = model·effort` (one reviewer's cell at one tier), `Resume = session | project | all | off` (what the resume block and the guide show: this session only, every session of this project — the default —, or other projects too; `off` (also `none`, `0`) = no automatic resume block at session start, after a compact or after a break — `/abofles:resume` still works and the guide is unaffected; override-only, not a `--default` value; a project `Resume = off` only stops the automatic block in the chat (start, compact, break); the pane's Resume card still shows. It also hides a user-level `Resume = <scope>` (first file wins), and the scope then falls back to the saved `--default` or project; `/abofles:resume --scope` wins for one call, `/abofles:resume --default` sets the user-wide default this line overrides), `Pace = normal | fast` (`fast` when the user says the plugin slows them: the direct-read guard speaks at 8/16/32/64 reads instead of 4/8/16/32, questions go to the user without a Judge only when the open task's tier (the highest of its agents and the task tier on the `main:` line) is 🟢/🟡 — 🟠/🔴 or an unknown tier are still judged —, and the receipt is the one-line form unless `Receipt` is set; the hooks themselves cost ~20–30 ms per tool call in either pace — the time goes to agents, so under `fast` also prefer the 1–3-call exception of rule 7 and background agents). `Guide place = pane | band`, `Resume place = pane | output` and `Agents place = pane | output` (where each thing shows; all three default to `pane`, the Abo Fles pane of the `abofles-guide` mod: the guide there instead of in the band above the prompt box, the resume block and the agent history there instead of printed in the chat — `output` / `band` keep today's view; a value that is none of the two is `pane`; without the mod there is no pane, so the guide stays in the band and the resume block and agent history are printed whatever the line says; `/abofles:resume` and `/abofles:history` print their text on demand either way, `/abofles:pane` opens or closes the pane). `Running place = pane | off` (default `pane`: the pane's Running page and Home's Running card, which show the live agents, background shells and scheduled wake-ups from engine events with no model call; `off` hides both). `Receipt place = pane | output` (default `pane` with the mod, `output` without it): with `pane` the Stop hook asks for the same receipt recorded by one command — `memo.py receipt` with the receipt lines on stdin — instead of printed; end the turn with one short sentence. The hook reads the recorded receipt as if it were printed (it closes the task, the review gate applies, the memo Journal and the pane's Resume › Last receipts get it), and the chat keeps one collapsed command row. `Memo on compact = auto | off` (default `auto`: the `PreCompact` hook tidies the memo and writes this session's Now from its last receipt when that is newer, the `PostCompact` hook writes Now from the compact summary (`· from compact`: Task from Current Work, Left from Pending Tasks, Next from the Optional Next Step; a hand-written Now not older than the last receipt is kept and only gets the Left lines it lacks) and saves the raw summary to `~/.abofles/state/compact/<session>.md` (never in the project); so `/compact` at a task boundary needs no `/abofles:memo` first — that stays optional, for a sharper Now; `off` = only `/abofles:memo` writes Now). `Continue after compact = auto | off` (default `auto`: after the person's own `/compact` the `abofles-guide` mod sends one turn — continue what the summary shows open, or say in a line or two that nothing is left to continue; never after an automatic compact, whose turn goes on by itself, nor while the person is typing; `off` = the session waits; without the mod nothing is sent). `Archive items = N` (days, default 7: a resolved Needs-you item older than that moves to `.claude/abofles-memo.d/archive.md`, ids and tags kept; over the 8 KB cap of the main memo the oldest resolved items move sooner, nothing is deleted) and `Archive sessions = N` (days, default 3: a session file idle that long with no open item of its own moves to `abofles-memo.d/archive/`, its index line to the `## Archive` list of archive.md; never the running session) — both applied by the memo health pass, at most every 6 hours at session start and before a compact; nothing is deleted. `Other items = hide | show` (default `hide`: the resume block and the pane leave out the open items and decisions of other sessions and other projects and say how many — `others: sessions, projects`; `show` lists them, marked `· other` in text and `other: true` in the pane; the guide never fills another session's or project's item). `Memo agent = auto | manual | off` (default `auto`), `Memo agent every = N` (hours, default 6) and `Memo repair = manual | auto` (default `manual`) are read by the memo-keeping steps that follow; they only need to be set when you want something other than the default. The pane's overrides editor (the Overrides card's `Edit overrides`) edits the simple keys (`Key = value`) in the project's or the user's file, with a `This project` / `All projects` toggle and `Reset` per key (a reset goes back one level: a project value gives way to the all-projects value, which a second reset clears); the forms with a name in them (cells, caps, tiers, `Reviewers`, `Workflow`, `Review`) are listed there as lines. The hooks read the project's `CLAUDE.md` first, then the user's `~/.claude/CLAUDE.md` — a line there applies to every project (`- Receipt = off` turns receipts off everywhere). Overrides are read **only** from the `## abofles overrides` block; a `- Key = value` line elsewhere in `CLAUDE.md` is prose and is ignored. Inside the block, a line in a code fence or an HTML comment is an example, not a setting; `*` and `+` bullets read like `-`. A word after a key's value is a note and is ignored (`Git guard = deny  # team rule` is `deny`); a value the hooks cannot read falls back to the key's default, and the pane's editor says so under that key. Check for this block before routing. Mark its use in the route line: ` · Project Override` (the topic lookup `scripts/topic.py` applies the cell, cap and tier forms itself and marks them).
